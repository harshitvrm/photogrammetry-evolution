# The Evolution of Photogrammetry
**Live site:** [Click here](https://harshitvrm.github.io/photogrammetry-evolution/)

**An interactive historical and scientific atlas of image-based 3D reconstruction** — from perspective geometry and the first photographic surveys to bundle adjustment, Structure from Motion, Neural Radiance Fields, 3D Gaussian Splatting and dynamic 4D reconstruction.

> *From measuring the physical world through photographs to reconstructing, representing, and experiencing the physical world in space and time.*

## Views

| View | What it shows |
|---|---|
| **Timeline**  | Six periods, 81 milestones with expandable cards, a chronological minimap with active-period tracking, Period 6 subdivided into five research threads, and a closing section on open problems. |
| **Lineage map**  | D3 network of the same events, placed by date (compressed scale) and discipline (rows). Node shape = type, colour = discipline, edge style = relation. Zoom, pan, reset, neighbourhood highlighting, "central spine" highlight, filter-aware. |
| **Technology** | Parallel tracks for capture, computation and representation, with curated couplings (including reverse influences). |
| **Compare**  | Six side-by-side comparisons, e.g. NeRF vs 3DGS, COLMAP vs VGGT, deformation-field vs native 4D Gaussians. |
| **About** | Purpose, dating conventions, source policy |

Global features: full-text search (title, people, institutions, reference titles, technical text; press `/`), period / discipline / status filters, a detail drawer with dating table (invention · first publication · adoption · improvements), uncertainty notes, incoming and outgoing lineage, related events and references, prev/next navigation and deep links.
